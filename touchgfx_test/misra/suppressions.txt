# Waveshare driver: STM32 GPIO port macros are integer-address-to-pointer
# casts, HAL SPI takes mutable buffers even for read-only transmit data, and
# ThreadX names are declared mutable. These are vendor API/hardware boundaries.
misra-c2012-11.4:*waveshare_driver.c

# MISRA 15.5 is advisory. The driver's early returns are argument/error guards;
# retaining them keeps failure paths direct and preserves the established flow.
misra-c2012-15.5:*waveshare_driver.c

# Chunked SPI/framebuffer transfers require bounded pointer stepping (Rule
# 18.4 advisory). Analyzer also mislabels the cursor update as Rule 10.3.
misra-c2012-18.4:*waveshare_driver.c
misra-c2012-10.3:*waveshare_driver.c

# Public module APIs and HAL callback overrides are consumed by callers outside
